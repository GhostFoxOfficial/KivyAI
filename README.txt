Hello! Thanks for using my ai named kivyai, he will be your great companion.

1. Install the zip

2. Unpack the archive

3. Before interacting with ai, you must execute these commands: ollama serve &
   ollama run qwen2.5:3b

4. Install gradio (if you haven't not yet, needed to launch web_app.py (the web application))

5. Launch web_app.py by typing python web_app.py (or by clicking play button on pydroid 3 if on android)

6. Go to the given url and now you all set! You now can interact with kivyai!


(Also you need to install ollama, good luck with the AI).
